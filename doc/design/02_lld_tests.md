### Interfaces

#### `config/judge.py` — `judge_llm()` + `throttled_invoke()`

Mirrors step4 (`config.py:215-233` + `eval/judge.py:28-30`).

```python
# --- env contract (read-only, no secrets in code) ---
# LLM_BASE_URL  — OpenAI-compatible endpoint (required)
# LLM_API_KEY   — auth token (required)
# LLM_MODEL     — model id, logical name only (default: "Qwen/Qwen2.5-7B-Instruct-AWQ" per D9)

def judge_llm() -> ChatOpenAI:
    """Build judge from env; raises RuntimeError if env missing."""

class _JudgeThrottle:
    """Global lock + ≥3.33s spacing (~18 req/min; step4 observed 429 at ~20 req/min)."""
    _lock: threading.Lock
    _last_send: float

def throttled_invoke(prompt: str, *, llm: ChatOpenAI) -> str:
    """Serialize judge calls through _JudgeThrottle. Returns JSON string."""

class JudgeError(Exception):
    """Typed error raised when salvage fails after 1 re-prompt."""
```

**Salvage path** (mirrors step4 intent, explicit in task 02):
1. `throttled_invoke` → parse JSON
2. If JSON invalid (JSONDecodeError or schema mismatch): strip markdown fences → retry **once**
3. If still invalid: raise `JudgeError` (typed, no secrets in message)

**JSON mode**: pass `response_format={"type": "json_object"}` if the endpoint supports it;
fall back to fence-strip + `json.loads` if it doesn't. pydantic validates the schema after parse.

#### `prompts/registry.json` — schema

Mirrors step4 (`prompts/prompt_registry.json`).

```json
{
  "prompts": {
    "<PROMPT_ID>_<SOURCE_TYPE>_<VERSION>": {
      "key": "<PROMPT_ID>_<SOURCE_TYPE>_<VERSION>",
      "prompt_id": "<PROMPT_ID>",
      "source_type": "<source_type>",
      "version": "<semver>",
      "template": "…system prompt text…",
      "input_variables": ["query", "context"],
      "model": "<logical model id, provenance only — no provider resolution here>",
      "status": "draft | approved | retired",
      "eval_scores": { "accuracy": 0.0, "latency_ms": 0 },
      "run_count": 0,
      "created_at": "ISO-8601",
      "updated_at": "ISO-8601"
    }
  }
}
```

**Composite key**: `prompt_id + source_type + version` — unique within the registry.

#### `prompts/registry.py` — lifecycle

```python
def load_registry(path: Path | None = None) -> dict:
    """Load registry.json; path defaults to this package's file."""

def save_registry(registry: dict, path: Path | None = None) -> None:
    """Dump to disk atomically."""

def approve(registry: dict, key: str) -> dict:
    """Set status='approved'; old approved → 'retired'. Returns updated registry."""

def rollback(registry: dict, key: str) -> dict:
    """Set status='retired'. Returns updated registry."""

def record_eval(registry: dict, key: str, accuracy: float, latency_ms: float) -> dict:
    """Write eval_scores + run_count += 1. Returns updated registry."""
```

**Lifecycle states**: `draft` → `approved` ↔ `retired`. Only one version per `prompt_id + source_type`
may be `approved` at a time; approving a new version retires the previous.

### Data flow

```
NB-002 (notebook-first, D2)
  │
  ├─ 1. Read env → judge_llm()
  │
  ├─ 2. Load registry.json → select approved prompt → render template
  │
  ├─ 3. throttled_invoke(rendered_prompt, llm=judge_llm())
  │        │
  │        ├─ Lock + spacing gate (≥3.33s)
  │        ├─ Invoke (response_format=json_object if supported)
  │        ├─ Parse → strip fences if needed → pydantic validate
  │        │   └─ invalid? → 1 re-prompt → JudgeError if still invalid
  │        └─ return JSON string
  │
  ├─ 4. Assert schema: winner, reasoning, score_a, score_b (task 02 exit criterion)
  │
  └─ 5. Save notebook → promote config/judge.py + prompts/{__init__,registry}.py
```

Generation ladder (`LLMProvider`, Groq→Gemini) is **not wired here** — it lands with Mod 4
(cost ladder). The judge reads `LLM_*` envs; generation reads `GROQ_*`/`GEMINI_*` envs;
the two never mix (D6, step4 `config.py:131-215`).

### Out of scope for this module

- Generation ladder (`LLMProvider`, `config/providers.py`, `config/models.py`) — Mod 4
- `config/env.py`, `config/paths.py` — land with their owning module
- DeepEval / Ragas wrappers — Mod 3 (task 03); they wrap `judge_llm()`
- Prompt template *files* beyond the registry slice — Mod 6 (lifecycle)
- Provider→model resolution in registry — stays in config, never registry (task 02:36-37)
